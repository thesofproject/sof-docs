Audio Processing Components API
###############################

SOF includes a rich library of standard audio processing components, covering volume control,
gain attenuation, channel mixing, IIR/FIR equalization, dynamic range compression (DRC),
sample rate conversion (SRC/ASRC), sound dose measurement, and acoustic filters.
