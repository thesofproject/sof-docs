.. _api_math:

DSP Math & Filter Libraries API
###############################

Digital signal processing routines in SOF provide optimized fixed-point and floating-point
mathematical routines. These include trigonometric approximations, polynomial functions,
CORDIC algorithms, Fast Fourier Transforms (FFT), IIR/FIR filter structures, and matrix
operations.
