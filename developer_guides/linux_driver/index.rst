SOF Linux Driver
################

The Sound Open Firmware (SOF) Linux kernel driver subsystem provides upstream ALSA System on Chip (ASoC) support for digital signal processors (DSPs) across Intel, NXP, AMD, and Mediatek hardware architectures.
